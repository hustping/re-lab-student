# 入门逆向安全靶场 - 学生攻防演练
> 本项目为网络安全课程教学靶场，仅用于**程序逆向分析、代码逻辑漏洞学习**。

## 📌 题目任务
分析提供的靶场程序 `lab-rev.exe`，获取程序内置flag字符串，完成演练解锁。

解题方式不唯一，可自行探索可行路径：
- 路径一：静态/动态逆向，分析程序校验逻辑，得到正确验证字符串；
- 路径二：探索本地环境下其他可行方式，绕过校验逻辑实现解锁。

> 🔔 学习规则
> 1. 请优先独立分析，锻炼逆向思维；**仅在完全没有解题思路时，再查看 source/src.zip 源代码作为参考**。不鼓励直接阅读源码“抄答案”，达不到训练效果。
> 2. ✅ **允许借助AI辅助分析**：可以使用大模型帮助理解汇编代码、解释程序逻辑、查询工具用法、梳理分析思路。
> 3. 提交的解题报告中，需要写明哪些环节使用了AI辅助，记录AI给你的提示与你自己的思考推导过程。

Challenge‑2：永久授权绕过（提高难度）
> 前置知识：授权状态机逻辑
程序授权完整流程：
1. 读取本地 license.dat 授权文件，授权内包含经过HMAC签名的服务端校验时间 `signed_verify_ts`
2. 如果当前时间距离签名校验时间小于7天，直接返回Pro激活状态
3. 超过7天，则请求远端 `/api/verify` 接口做联网校验
    - 接口正常返回：更新签名时间戳，进入7天信任窗口，Pro
    - 接口返回拒绝：直接删除本地授权，回到Free
    - 网络故障：进入最长30天离线宽限期；宽限期耗尽同样清除授权回到Free

📌 题目要求：
实现程序**永久处于Pro激活状态**。
⚠️ 约束条件：
1. 不允许反复修改操作系统系统时间作为解题手段；
2. 仅构造7天短期合法授权，只能获得临时Pro，不计为完成本题。

可行探索方向（二选一完成即可）：
- 方向1：逆向分析签名校验逻辑，利用客户端硬编码密钥，伪造一个永不超时的合法签名授权文件；
- 方向2：逆向程序二进制，劫持/绕过整套授权状态机判断逻辑，强制程序输出激活状态，跳过7天TTL、联网请求、30天宽限、拒绝清除全部逻辑。
