# 入门逆向安全靶场 - 学生攻防演练
> 本项目为网络安全课程教学靶场，仅用于**程序逆向分析、代码逻辑漏洞学习**。

## 📌 题目任务
分析提供的编译程序 `lab-rev.exe`，找到程序内置的flag字符串，提交flag完成演练。
程序内存在一处简单代码逻辑缺陷，你可以使用静态/动态逆向工具进行分析。

> 🔔 学习规则
> 请优先独立分析，锻炼逆向思维；**仅在完全没有解题思路时，再查看 src.zip 源代码作为参考**。允许借助AI辅助分析**：可以使用大模型帮助理解汇编代码、解释程序逻辑、查询工具用法、梳理分析思路。 提交的解题报告中，需要写明哪些环节使用了AI辅助，记录AI给你的提示与你自己的思考推导过程
> 不鼓励直接阅读源码“抄答案”，达不到训练效果。

## 📁 文件说明
- `lab-rev.exe`：靶场可执行程序，题目本体
- `src.zip`：靶场完整源代码（提示素材，建议最后再看）
- `writeup_template.md`：学生提交解题报告模板，需要记录分析过程、工具、思路
